# T: แถบเครื่องมือเยอะ ลายตา กินพื้นที่ (ปัญหาข้อ 3 ของผม)
เป้า: แถบที่ติดจอบนเดสก์ท็อปสูงไม่เกิน 72px และมือถือรวมบนกับล่างไม่เกิน 112px
T1. เดสก์ท็อป: เหลือแถบติดจอแถบเดียว สูงประมาณ 64px
   - ซ้าย: โลโก้กับชื่อ (ตัดป้าย v2.2 ออก)
   - กลาง: ตัวสลับโหมดแบบ segmented control 3 ช่อง ไอคอนกับคำไทยสั้น "นักท่องเที่ยว · ร้านและโรงแรม · ผู้บริหาร" (ตัดเลข 1. 2. 3. และวงเล็บภาษาอังกฤษออก)
   - ขวา: ปุ่มไอคอน ตะกร้า (มีตัวเลข) · คูปอง · ธีม (ไอคอนเดียวสลับได้) · เมนู
   - เมนูหน้า "หน้าแรก / แอป / เครดิต" ย้ายเข้าเมนู
T2. มือถือ: แถบบนสูง 56px (โลโก้ · ตะกร้า · เมนู) + แถบโหมดด้านล่างจอแบบ tab bar สูง 56px บวก safe-area (3 แท็บ ไอคอนอยู่บนคำ) · ห้ามมีแถวปุ่มเรียงซ้อนลงมาแบบตอนนี้
T3. ลบแถวชิปทั้งแถว ("แผนที่ 3D พิกัดจริง (13 หมุด)", "5 โบราณสถาน · 5 ร้านดัง · 3 โรงแรม", "AI Audio Guide …", "VIP Pass 99฿" และชิปฝั่งผู้บริหาร) แล้วย้ายหน้าที่ไปไว้ตรงที่ใช้จริง:
   - ปุ่มเสียงบรรยาย → อยู่ในการ์ดสถานที่
   - VIP Pass → การ์ดเดียวในหน้านักท่องเที่ยว
   - ส่วนต่างๆ ของหน้าผู้บริหาร → แท็บภายในหน้า (ไม่ติดจอ)
T4. ปุ่มกรองหมวดและเครื่องมือแผนที่ย้ายเข้าไปลอยอยู่บนแผนที่ (มุมขวาบน):
   - ชิปกรอง 4 หมวดแบบไอคอนกับจำนวน (ตัดวงเล็บเหลี่ยม [ ] ออก)
   - ปุ่มเต็มจอ (ตามข้อ R3 ใน v2.3) · ปุ่มกลับมุมมองเริ่มต้น · ปุ่มเปิดปิดคำอธิบายสัญลักษณ์
   - บนมือถือให้เลื่อนแถบนี้ซ้ายขวาได้ภายในแผนที่
T5. ความสูงแผนที่: เดสก์ท็อปเท่ากับ 100vh ลบ 64px ลบระยะขอบ (ไม่ต่ำกว่า 560px) · มือถือ 70vh
T6. การ์ดรายละเอียดสถานที่บนมือถือ: เปลี่ยนเป็น bottom sheet ซ้อนบนแผนที่ ลากขึ้นลงได้ (สูงครึ่งจอ / เต็มจอ / ซ่อน) แทนการต่อท้ายลงไปจนหน้ายาว 15,000px · เดสก์ท็อปคงไว้คอลัมน์ขวา
